製品の機能

取り込みから確認、検索、保管、提出準備までを一つのアプリで。実際のアプリ画面でご紹介します。

IMPORT

まとめて取り込み

PDF、画像、テキスト、メール(.eml)をドラッグ&ドロップで取り込みます。フォルダごとの取り込みにも対応。元のファイルは変更しません。同じ内容のファイルは自動で除外します。

READ

読み取り結果を「候補」として表示

取引日(西暦・和暦)、金額、取引先、書類の種類、登録番号を読み取り、確度を色で示します。画像からはWindows標準のOCRで候補を表示します(端末内で処理)。

自動では確定しません。原本のプレビューと並べて確認し、Enterで確定します。

WARN

疑わしい読み取りへの警告

金額が小計や税額と合わないとき(桁落ちなど)は、疑わしい値を空欄にして、計算から導いた候補を示します。登録番号は形式を確認し、読めなかった項目は「未読」と表示します。

警告が出ない誤りもあります。確認は必ず行ってください。

FLOW

確認して次へ、をテンポよく

確定すると次の書類へ進みます。確度が高い書類を条件つきで一括確定する機能もありますが、確認を省くための機能ではありません。内容は、あとから台帳でも見直せます。

保管時のファイル名は 20261020_12100_ことり文具株式会社_納品書.pdf のような規則的な形になります。

SEARCH

台帳と検索

期間、金額の範囲、取引先、書類の種類、全文(本文・メモ・ファイル名)を組み合わせて検索。「今月・先月・今年・昨年」のワンクリック指定や、索引簿のCSV / Excel出力も備えます。一度確定した取引先は学習し、次回から優先して当てはめます。

KEEP

保全と提出

保管後のファイル・台帳・履歴の食い違いを確認する整合性チェック、原本・索引簿・ハッシュ一覧・履歴をまとめる提出パック、別ドライブへのコピー、検査つきの復元を備えます。

整合性チェックは、誤操作や意図しない変更に「気づく」ための機能です。管理者権限を持つ人がデータ全体を作り直した場合は、PC内のチェックでは検出できません。改ざんがないことの証明ではありません。

MORE

そのほかの機能

訂正・取消の履歴

物理削除はせず、変更前後の値・理由・担当者名を履歴に記録します。

事務処理規程のたたき台

国税庁サンプルの構成に沿ったWord文書を作成します。定めて運用するのは利用者です。

導入ガイドとデモ帳票

架空の帳票で、本番の前に一通り練習できます。

バックアップと復元

外付けドライブ等へのコピー、台帳の自動バックアップ、検査つきの復元。

ソフトに閉じ込めません

保管先はただのフォルダです。ファイルと索引簿(CSV)は、ソフトがなくても読めます。

通信なし

書類の内容や利用状況を外部へ送信しません。ライセンス認証もありません。

対応していないこと

  • 紙の書類のスキャナ保存(紙は紙のまま保存してください)
  • 会計帳簿の電子保存、会計ソフトとの連携
  • タイムスタンプの付与
  • メール・クラウドからの自動収集
  • 複数人での同時利用
  • 手書き書類の読み取り

読み取り結果は、必ず人が確認してください

ShohyoDockの読み取りは「候補の表示」です。誤ることがあり、自動では確定しません。確定前に必ず原本と見比べてください。

実際の帳票での読み取りの正確さは、まだ検証できていません。製作者が試したのは架空の帳票のみで、実際の帳票より読みやすい可能性があります。精度の数値による保証はできません。お手持ちの帳票で使えるかどうかは、体験版の公開後にお確かめください(現在は準備中です)。

体験版の公開をお待ちください

体験版は、製品版と同じ機能で確定できる書類が30件までの予定です(現在は公開準備中)。購入前に、お手持ちの帳票で試せる状態を整えています。

体験版は公開準備中製品版は販売準備中

※体験版は現在公開準備中です。ダウンロードできるようになるまで、ボタンは無効です。

※製品版は販売準備中です。BOOTHの商品ページが公開されるまで、購入はできません。
