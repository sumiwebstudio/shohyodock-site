OVERVIEW

What it does

Import

Drag and drop PDFs, images, text and .eml files. Original files are never modified; duplicates are skipped.

Review

Date, amount, vendor, document type and registration number are shown as candidates using Windows built-in OCR. Nothing is confirmed automatically.

Keep & search

Files are stored with regular names (date_amount_vendor_type). Search the ledger and export CSV / Excel, create submission ZIPs, back up and restore.

LEDGER

Search by date, amount, vendor and full text

Confirmed documents appear in the ledger, with correction history and integrity checks.

Important

  • OCR output is a suggestion and can be wrong. A person must always check it against the original before confirming.
  • Accuracy on real-world invoices has not been verified. Once the trial is released, please try it with your own documents first.
  • ShohyoDock does not guarantee compliance with Japan's Electronic Books Preservation Act or any other law, and is not JIIMA-certified. It does not support scanner preservation of paper documents.
  • Verified on Windows 11 x64. Windows 10 is untested. The interface and documentation are in Japanese.
